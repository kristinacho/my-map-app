# Приложение «Карта и изображения»

Лабораторная работа по дисциплине «Технологии мобильной разработки».

## Описание

Мобильное приложение на React Native, Expo и TypeScript. Позволяет размещать маркеры на карте и прикреплять фотографии к выбранным местам.

## Возможности

- Интерактивная карта с перемещением и масштабированием.
- Создание маркера долгим нажатием на карту.
- Просмотр координат выбранного маркера.
- Переход на экран деталей маркера и возврат назад.
- Добавление фотографий из галереи телефона.
- Просмотр количества и списка фотографий.
- Удаление фотографии с подтверждением.
- Обработка отмены выбора изображения, ошибок и загрузки карты.

## Технологии

- React Native
- Expo (SDK 58)
- TypeScript
- Expo Router
- react-native-maps
- expo-image-picker
- React Context для общего состояния маркеров

## Установка и запуск

1. Установить Node.js и приложение Expo Go на телефон.
2. Склонировать репозиторий и перейти в каталог проекта.
3. Установить зависимости:

   ```powershell
   npm.cmd install
   ```

4. Запустить Expo:

   ```powershell
   npx.cmd expo start
   ```

5. Открыть приложение на телефоне через QR-код в Expo Go.

> Для проверки использовался iPhone. Версия Expo Go должна поддерживать SDK проекта.

## Проверка TypeScript

```powershell
npx.cmd tsc --noEmit
```

## Основные решения

- Навигация между экранами построена на файловых маршрутах Expo Router.
- Данные маркеров и их изображений описаны интерфейсами TypeScript.
- Состояние маркеров доступно нескольким экранам через React Context (`MarkersProvider`).
- Изображения выбираются через системный интерфейс `expo-image-picker`.

## Известные ограничения

- **Если данные хранятся только в React Context:** маркеры и их фотографии не сохраняются при полном перезапуске приложения.
- Работа проверена на iOS через Expo Go; Android отдельно не тестировался.

# Map & Images — мобильное приложение на Expo

Учебный проект по дисциплине «Технологии мобильной разработки». Приложение разрабатывается в три этапа. В текущей версии реализованы **лабораторная работа №1 (карта и изображения)** и **лабораторная работа №2 (локальная база данных SQLite)**.

## Возможности

- Просмотр интерактивной карты, перемещение и масштабирование.
- Добавление маркера долгим нажатием на карту.
- Открытие экрана маркера с координатами.
- Выбор фотографий из галереи, просмотр списка и удаление фотографий.
- Удаление маркера с подтверждением.
- Сохранение маркеров и изображений после полного перезапуска приложения.
- Индикация загрузки карты, обработка ошибок и возврат к карте.

## Технологии

- **React Native + Expo (SDK 58)** — мобильное приложение и запуск через Expo Go.
- **TypeScript** — типизация данных и компонентов.
- **react-native-maps** — карта и маркеры.
- **expo-router** — маршрутизация между экранами.
- **expo-image-picker** — выбор изображений.
- **expo-sqlite** — локальная реляционная база данных.
- **expo-file-system** — хранение файлов изображений в каталоге приложения.
- **React Context** — доступ к БД и состоянию маркеров.

## Установка и запуск

Требования: установленный Node.js с npm, мобильное приложение **Expo Go**, совместимое с SDK проекта, и телефон для тестирования.

Из корневой папки проекта выполните команды в PowerShell:

```powershell
npm.cmd install
npx.cmd expo start
```

После запуска отсканируйте QR-код через Expo Go на телефоне. При необходимости перезапуска с очисткой кэша:

```powershell
npx.cmd expo start --clear
```

Проверка TypeScript и совместимости установленных зависимостей:

```powershell
npx.cmd tsc --noEmit
npx.cmd expo install --check
```

> Здесь использованы `npm.cmd` и `npx.cmd` для Windows PowerShell. Если в вашей системе работают обычные `npm` и `npx`, можно использовать их.

## Использование

1. Откройте карту и удерживайте палец на нужной точке, чтобы добавить маркер.
2. Нажмите на маркер, чтобы перейти к его деталям и увидеть координаты.
3. Нажмите «Добавить изображение», выберите фотографию из галереи.
4. При необходимости удалите отдельное изображение либо весь маркер, подтвердив удаление.
5. Закройте и снова откройте приложение: сохранённые данные должны загрузиться из SQLite.

## Лабораторная работа №1 — карта и изображения

Реализованы интерактивная карта, добавление и отображение маркеров, экран деталей с координатами, выбор фотографий из галереи, список фотографий и удаление. Для переходов между экранами используется файловая маршрутизация Expo Router. Предусмотрена обработка ошибок навигации и выбора изображений, а также индикация загрузки карты.

## Лабораторная работа №2 — локальная БД SQLite

### Схема базы данных

База данных `markers.db` содержит две связанные таблицы.

**`markers`** — данные точек на карте:

| Поле         | Тип                                  | Назначение             |
| ------------ | ------------------------------------ | ---------------------- |
| `id`         | `INTEGER PRIMARY KEY AUTOINCREMENT`  | Первичный ключ маркера |
| `latitude`   | `REAL NOT NULL`                      | Широта                 |
| `longitude`  | `REAL NOT NULL`                      | Долгота                |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | Дата создания          |

**`marker_images`** — сведения о фотографиях:

| Поле         | Тип                                  | Назначение                 |
| ------------ | ------------------------------------ | -------------------------- |
| `id`         | `INTEGER PRIMARY KEY AUTOINCREMENT`  | Первичный ключ изображения |
| `marker_id`  | `INTEGER NOT NULL`                   | ID связанного маркера      |
| `uri`        | `TEXT NOT NULL`                      | Локальный URI файла        |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | Дата создания              |

Между таблицами установлена связь **один ко многим**: одному маркеру соответствует несколько изображений. Внешний ключ `marker_images.marker_id` ссылается на `markers.id` и использует `ON DELETE CASCADE`. При удалении маркера связанные **строки базы данных** удаляются автоматически при включённом `PRAGMA foreign_keys = ON`.

### Операции с данными

Реализованы создание, получение и удаление маркеров; добавление, получение и удаление изображений. База открывается через асинхронный API `expo-sqlite`. При инициализации создаются таблицы и индекс по `marker_id`, включается контроль внешних ключей, проверяется версия схемы (`PRAGMA user_version`). SQL-запросы отделены от UI в `src/database/operations.ts`.

### Работа с React Context

`DatabaseContext` управляет доступом к соединению SQLite, предоставляет асинхронные операции, состояния загрузки и ошибки. `MarkersContext` поддерживает данные маркеров для отображения в интерфейсе и связывает пользовательские действия с операциями базы. Такое разделение не требует писать SQL непосредственно внутри экранов.

### Обработка ошибок

- При инициализации БД исключения перехватываются, ошибки сохраняются в контексте и выводятся в журнал разработки.
- Ошибки операций с БД передаются вызывающему коду для обработки.
- При открытии отсутствующего маркера показывается сообщение и доступен возврат к карте.
- При выборе изображений обрабатывается отмена действия и отсутствие выбранного файла.
- Удаление маркера требует подтверждения.
- При долгой загрузке карты выводится сообщение и предлагается повторная попытка.

## Особенности и ограничения

- Приложение работает с **локальными данными**; серверная синхронизация и учётные записи не предусмотрены.
- SQLite хранит **записи о фотографиях и их URI**, а сами файлы сохраняются отдельно в хранилище приложения.
- Каскадное удаление SQL-записей не означает автоматического физического удаления файлов с устройства. Очистка файлов должна выполняться отдельно; её наличие следует проверять по реализации.
- При удалении приложения локальные данные могут быть потеряны.
- Работа проверялась в **Expo Go на iPhone**: создание маркеров, фотографии, удаление, навигация и сохранение после перезапуска.
