# Приложение «Карта и изображения»

Лабораторная работа по дисциплине «Технологии мобильной разработки».

## Описание

Мобильное приложение на React Native, Expo и TypeScript. Позволяет размещать маркеры на карте и прикреплять фотографии к выбранным местам.

## Возможности

- Интерактивная карта с перемещением и масштабированием.
- Создание маркера долгим нажатием на карту.
- Просмотр координат выбранного маркера.
- Переход на экран деталей маркера и возврат назад.
- Добавление фотографий из галереи телефона.
- Просмотр количества и списка фотографий.
- Удаление фотографии с подтверждением.
- Обработка отмены выбора изображения, ошибок и загрузки карты.

## Технологии

- React Native
- Expo (SDK 58)
- TypeScript
- Expo Router
- react-native-maps
- expo-image-picker
- React Context для общего состояния маркеров

## Установка и запуск

1. Установить Node.js и приложение Expo Go на телефон.
2. Склонировать репозиторий и перейти в каталог проекта.
3. Установить зависимости:

   ```powershell
   npm.cmd install
   ```

4. Запустить Expo:

   ```powershell
   npx.cmd expo start
   ```

5. Открыть приложение на телефоне через QR-код в Expo Go.

> Для проверки использовался iPhone. Версия Expo Go должна поддерживать SDK проекта.

## Проверка TypeScript

```powershell
npx.cmd tsc --noEmit
```

## Основные решения

- Навигация между экранами построена на файловых маршрутах Expo Router.
- Данные маркеров и их изображений описаны интерфейсами TypeScript.
- Состояние маркеров доступно нескольким экранам через React Context (`MarkersProvider`).
- Изображения выбираются через системный интерфейс `expo-image-picker`.

## Известные ограничения

- **Если данные хранятся только в React Context:** маркеры и их фотографии не сохраняются при полном перезапуске приложения.
- Работа проверена на iOS через Expo Go; Android отдельно не тестировался.
