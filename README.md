# Map & Images — карта, фотографии и геолокация

мобильное приложение, разработанное на **React Native, Expo SDK 58 и TypeScript**. В одном проекте объединены три лабораторные работы:

1. Интерактивная карта, маркеры и фотографии.
2. Локальное хранение данных в SQLite.
3. Геолокация, вычисление расстояний и уведомления при приближении к маркерам.

## Возможности

- Просмотр интерактивной карты, изменение масштаба и перемещение по ней.
- Создание маркера долгим нажатием на карту и открытие его экрана с координатами.
- Добавление фотографий из галереи, просмотр и удаление фотографий.
- Удаление маркера с подтверждением.
- Сохранение маркеров и информации об изображениях в локальной SQLite-базе, восстановление при следующем запуске.
- Отображение текущего местоположения пользователя синей точкой после предоставления разрешения.
- Автоматическое перемещение камеры карты к текущему местоположению при первом его определении (без постоянного принудительного центрирования).
- Расчёт расстояния до маркеров и отображение расстояния до ближайшей метки.
- Локальное уведомление при попадании в радиус **100 м** от маркера.
- Защита от повторных уведомлений, пока пользователь остаётся внутри зоны; повторное уведомление возможно после выхода и нового входа.
- Последовательная нумерация видимых маркеров («Маркер 1», «Маркер 2» и т. д.) независимо от постоянных ID в базе.
- Обработка ошибок геолокации, разрешений, загрузки карты и операций с данными.

## Установка и запуск

**Требования:** Node.js с npm, установленное приложение **Expo Go** совместимой версии и смартфон. Основная проверка выполнялась на **iPhone**.

Откройте PowerShell в корневом каталоге проекта:

```powershell
npm.cmd install
npx.cmd expo start
```

Отсканируйте QR-код и откройте приложение через Expo Go.

Если после изменений приложение работает некорректно, можно очистить кэш:

```powershell
npx.cmd expo start --clear
```

Проверка зависимостей и TypeScript:

```powershell
npx.cmd expo install --check
npx.cmd tsc --noEmit
```

> Команды `npm.cmd` и `npx.cmd` приведены для Windows PowerShell. При первом запуске разрешите приложению доступ к местоположению и уведомлениям, когда iOS покажет соответствующие запросы.

## Как пользоваться

1. **Откройте карту.** После разрешения доступа к геолокации появится синяя точка; карта переместится к вашему местоположению.
2. **Создайте маркер.** Удерживайте палец на карте в нужной точке.
3. **Посмотрите расстояние.** Нажмите на маркер, чтобы увидеть расстояние до него во всплывающей подписи; в нижней панели показывается расстояние до ближайшей метки.
4. **Откройте детали.** Нажмите на маркер для просмотра координат, добавления фотографий из галереи и удаления изображений.
5. **Удалите маркер.** Подтвердите удаление на экране деталей. Отображаемые номера оставшихся маркеров обновятся автоматически.
6. **Проверьте уведомления.** При приближении к сохранённому маркеру на расстояние 100 м приложение отправляет локальное уведомление. Повторное уведомление для той же зоны появится только после выхода из неё и повторного входа.
7. **Проверьте сохранность данных.** Полностью закройте и повторно откройте приложение: маркеры и связанные фотографии должны сохраниться.

## Лабораторная работа №1 — карта и фотографии

Реализована интерактивная карта с добавлением маркеров долгим нажатием. При нажатии на маркер открывается отдельный экран с координатами, возможностью прикрепить фотографии из галереи, просмотреть их и удалить. Навигация построена на **Expo Router**. Для карты предусмотрены состояние загрузки и возможность повторной попытки при длительном ожидании.

## Лабораторная работа №2 — локальная база SQLite

Приложение использует файл **`markers.db`**, в котором находятся две связанные таблицы:

| Таблица         | Поля                                        | Назначение                            |
| --------------- | ------------------------------------------- | ------------------------------------- |
| `markers`       | `id`, `latitude`, `longitude`, `created_at` | Координаты и дата создания маркеров   |
| `marker_images` | `id`, `marker_id`, `uri`, `created_at`      | URI фотографий, связанных с маркерами |

Отношение между таблицами — **один ко многим**: у одного маркера может быть несколько фотографий. Внешний ключ `marker_images.marker_id` связан с `markers.id` и использует `ON DELETE CASCADE` для удаления связанных **записей БД**.

При инициализации создаются необходимые таблицы, включается контроль внешних ключей, используется проверка версии схемы (`PRAGMA user_version`). SQL-операции отделены от компонентов и выполняются через асинхронный API `expo-sqlite`.

Сами изображения находятся в файловом хранилище приложения, а в SQLite сохраняются их URI. `DatabaseContext` предоставляет доступ к операциям с БД; `MarkersContext` хранит актуальные данные для интерфейса.

## Лабораторная работа №3 — геолокация и уведомления

### Определение местоположения

Хук `useUserLocation` работает через `expo-location`:

- Проверяет, включены ли службы геолокации на устройстве.
- Запрашивает разрешение на использование местоположения **во время работы приложения**.
- Подписывается на изменения координат с помощью `watchPositionAsync`.
- Освобождает подписку при размонтировании компонента.
- Передаёт актуальные координаты и возможную ошибку компоненту карты.

При получении первой позиции карта однократно центрируется на пользователе; затем её можно свободно перемещать вручную.

### Расстояние до маркеров

Функции в `src/utils/distance.ts` вычисляют расстояния по географическим координатам и форматируют результат для отображения. На карте расстояние показывается в описании маркера, а нижняя панель выводит расстояние до ближайшей сохранённой метки.

### Локальные уведомления

Хук `useProximityNotifications` использует текущие координаты и список сохранённых маркеров. При входе в зону **100 метров** от маркера формируется локальное уведомление через `expo-notifications`.

Чтобы уведомления не приходили при каждом обновлении GPS, для маркера учитывается факт нахождения внутри зоны. После выхода за пределы радиуса состояние сбрасывается, и при следующем входе уведомление снова возможно.

## Ограничения

- Приложение рассчитано на **локальное использование**, без аккаунтов и серверной синхронизации.
- Геолокация реализована для **открытого приложения**; полноценное отслеживание в фоне не заявлено.
- Точность GPS зависит от устройства, сигнала и настроек разрешений. Граница радиуса 100 м может срабатывать с погрешностью.
- Уведомления зависят от разрешений iOS и поддержки функций в текущей среде Expo Go.
